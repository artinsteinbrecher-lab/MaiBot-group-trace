# 命令与例子

## 寻找群聊历史

```text
/寻迹 群号 线索
```

示例：

```text
/寻迹 123456789 找之前关于 DSV4F 默认 64K 和 Max 配置的讨论
```

插件会：

1. 理解你的查询目标和相关别名。
2. 读取白名单中指定群的现有历史消息。
3. 本地筛选候选，再进行可选的嵌入语义重排。
4. 补齐相关消息前后的对话。
5. 根据证据回答，并使用 `[E1]` 这样的编号引用原始消息。

回复一条文字消息后也可以使用：

```text
/寻迹 123456789
```

## 创建复合观察规则

```text
/监控创建 群号 你的要求
```

示例：

```text
/监控创建 123456789 关注 DSV4F 输出限制，提到 64K、384K 或 max_tokens 时提醒，价格讨论不用管
```

麦麦只生成草稿，不会立刻开始监控。检查草稿后选择：

```text
/监控确认
/监控取消
```

草稿保存 15 分钟；超时后需要重新创建。

## 管理规则

```text
/监控列表
/监控暂停 规则编号
/监控恢复 规则编号
/监控删除 规则编号
```

每位管理员只能管理自己创建的规则。

## 查看可访问群聊

```text
/寻迹群列表
```

只展示同时满足两个条件的群：

- 已经填写在插件群聊白名单中。
- MaiBot 当前已经建立对应聊天流。

## 帮助

