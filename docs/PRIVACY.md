# 权限和隐私

## 默认拒绝

插件首次安装时：

- 管理员名单为空。
- 群聊白名单为空。
- 外部查询关闭。

因此插件不会默认开放跨群检索，也不会默认读取任何群的新消息。

## 数据保存位置

规则、待确认草稿和命中记录写入 MaiBot 为插件分配的专属数据目录：

```text
data/plugins/github.artinsteinbrecher-lab.group-trace/group_trace.sqlite3
```

插件不会把运行数据写入源码目录，也不会修改 MaiBot 主数据库结构。

内存中的最近消息窗口在插件卸载或 MaiBot 重启后消失。群聊历史寻迹读取的是 MaiBot 已经保存的消息。

## 发送给模型的内容

- 创建规则时：发送用户的规则描述和目标群号。
- 语义复核时：只发送本地规则已经命中的有限上下文。
- 历史寻迹时：只发送筛选后的有限证据，不发送整群完整历史。

如果使用第三方模型供应商，应同时遵守供应商的数据处理规则。

## 外部查询

外部查询默认关闭。启用后只发送生成的查询词，不发送完整群聊记录。

API 密钥不会写入插件日志或聊天输出，但实际配置仍保存在服务器安装目录的 `config.toml` 中，应限制该文件的系统访问权限。

## 删除数据

聊天命令可以删除单条规则。彻底移除插件数据时，先卸载插件，再由服务器管理员删除对应的插件专属数据目录。
